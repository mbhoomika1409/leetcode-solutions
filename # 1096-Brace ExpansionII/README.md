# 1096. Brace Expansion II

## Problem

Given a string expression containing lowercase letters, `{}`, `,`, and concatenation, return all possible words that can be generated from the expression.

The result must contain **no duplicates** and must be returned in **lexicographical order**.

## Example

### Input

```text
expression = "{a,b}{c,d}"
```

### Output

```text
["ac","ad","bc","bd"]
```

## Approach

The solution uses **recursion** and **sets**.

* `{a,b}` represents a **union** → `a` or `b`
* `{c,d}` represents a **union** → `c` or `d`
* Concatenation combines every result from the first part with every result from the second part.
* A `set` automatically removes duplicate strings.
* Finally, `sorted()` returns the answers in lexicographical order.

## Key Concepts

* Recursion
* Sets
* Union
* Cartesian product
* String concatenation
* Lexicographical sorting

## Python Solution

```python
class Solution:
    def braceExpansionII(self, expression):
        def parse(i):
            result = {""}
            current = set()

            while i < len(expression) and expression[i] != '}':
                if expression[i] == '{':
                    part, i = parse(i + 1)

                elif expression[i] == ',':
                    result |= current
                    current = set()
                    i += 1
                    continue

                else:
                    part = {expression[i]}
                    i += 1

                current = {
                    a + b
                    for a in current or {""}
                    for b in part
                }

            result |= current
            return result, i + 1

        return sorted(parse(0)[0])
```

## Complexity

The complexity depends on the number of unique strings generated by the expression because the number of possible expansions can grow rapidly.

## Key Learning

The most important idea is:

```text
Comma (,)        → UNION
Next expression  → CONCATENATION
Set              → Remove duplicates
Recursion        → Handle nested braces
Sorted()         → Lexicographical order
```
